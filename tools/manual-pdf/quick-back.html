The TS-Pico plugs into the Timex Sinclair 2068 and gives it a micro SD card: LOAD and SAVE in moments instead of minutes.

This guide covers the first steps, from fitting the TS-Pico to loading a program. The TS-Pico User Manual covers the rest: saving single files, streams, the virtual printer, ROM slots and cartridges, ZX Spectrum mode, and every command and report. The Quick Reference Guide puts the commands on one folded card.
