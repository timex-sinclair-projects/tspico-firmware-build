TS-Pico Command              REW
--------------------------------
SAVE "tpi:rew"[CODE 0/1/2/3,n]

Moves current tap file pointer
backwards by blocks or headers.
No CODE: 1 block.
CODE 0,n: Move n blocks
CODE 1,n: n blocks, then tapdir
CODE 2,n: Move n headers/files
CODE 3,n: n headers, then tapdir

See also: ffw, tapdir
