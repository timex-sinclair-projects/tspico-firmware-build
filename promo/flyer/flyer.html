Free update for TS-Pico owners

TS-Pico 2.3CAT. MOVE. ERASE. FORMAT.

The disk keywords Timex built into the 2068 and never finished now work, on your TS-Pico's SD card. Version 2.3 replaces 1.1, and installs from a web browser in about fifteen minutes.

CAT: the folder in color, with the card's size and free space.

Disk commands in BASIC

CAT lists the card, MOVE copies files and changes folder, ERASE deletes, and FORMAT makes a new tape or folder. Wildcards and paths included.

CAT "games/b*"
MOVE "*.tap" TO "backup"

Single files with f:

LOAD, SAVE, VERIFY and MERGE a file of its own, outside any TAP. Screens save as the plain 6,912 bytes your computer's picture tools can open.

SAVE "f:advent.bas" LINE 10
LOAD "f:title.scr" SCREEN$

Files your programs can read and write

OPEN #, PRINT # and INPUT # work with files on the card: high-score tables, notes, logs, record files with TAB, even a folder listing.

OPEN #4,"f:notes.txt","w"

A printer on the card

LPRINT and LLIST go to text files on the card, and COPY saves the screen as a BMP picture: second screen, hi-color and 512 columns included.

SAVE "tpi:picopt"
COPY

A menu when nothing is mounted

LOAD "" with no tape mounted loads a menu: help on every command, a file picker, and the TS-Pico Commander, a full-screen file manager you drive with the cursor keys.

1,327 programs, ready to copy

The TS-2068 Software Library: every program test-loaded with the TS-Pico firmware, sorted into folders, with short names you can type and a catalog. Free, from archive.org.

Help on the card

A help page for every TS-Pico command and BASIC keyword, right on the 2068.

Inside a tape

CAT "" lists the blocks in the mounted TAP and shows where the tape pointer is. FORMAT "songs.tap" starts a new, empty tape.

ZX Spectrum mode

Mount another tape and list the folder without leaving Spectrum mode, with the new Spectrum ROM in flash slot 0.

Manuals and open source

A new User Manual, as a PDF to read or a booklet to print, and a Programmer's Manual. The firmware is open source (MIT) on GitHub.

CAT "": the blocks on the mounted tape; the next one is highlighted.
SAVE "tpi:cd": pick a folder by its number.
SAVE "tpi:info": firmware, ROM and card at a glance.

Fixed since 1.1

  • No more Report D or J on big files. A rebuilt two-port link with a real ready/busy handshake.
  • BREAK works. CAPS SHIFT + SPACE stops any TS-Pico command, and the next one works normally.
  • No twenty-second hangs. If a transfer goes wrong you get T TS-Pico reset, try again at once.
  • Swap SD cards freely. New files show up without a restart; the TS-Pico runs without a card.
  • LOAD gives up when there's nothing to find. One pass of the tape, then R Tape loading error, instead of an endless wait.
  • Flash slots are safer. The TS-Pico refuses to overwrite the ROM the 2068 is running.

One change to know. TS-Pico commands are now SAVE commands: SAVE "tpi:dir", SAVE "tpi:info". LOAD "tpi:name.tap" mounts a file.

Upgrade in fifteen minutes. It's free.

  1. Switch the TS 2068 off. Keep the TS-Pico's P10 jumper fitted.
  2. Open the web updater in Chrome or Edge, connect the TS-Pico by USB, choose Latest release. On Windows you can run TS-Pico-Updater.exe instead.
  3. Coming from 1.1, leave Erase the Pico first and Update the TS-2068 ROM ticked, and follow the steps. Afterwards PRINT PEEK 101 gives 35.
