Upgrade your TS-Pico

Leave the TS-Pico plugged into the TS-2068 and connect the Pico’s Micro-USB port to this computer. Close Thonny or anything else using the Pico.

Switch the TS-2068 off before you start: the USB cable powers the Pico, and the Pico should only be reflashed or restarted with the 2068 off. You’ll turn the 2068 on for the ROM update, if you choose it, and the page tells you when to switch it off again.

  1. Connect
    Reads what’s installed and picks the right steps.
    It won’t connect / the Pico has no working firmware

    Put it into BOOTSEL mode by hand, then press Start below without connecting:

    1. Switch the TS-2068 off.
    2. Plug the USB cable into the Pico and your computer.
    3. Press and hold the Pico’s BOOTSEL button (the little white button next to the Micro-USB connector).
    4. While holding it, press and release the TS-Pico’s Pico reset button (or unplug and replug the USB cable).
    5. Release BOOTSEL. A drive named RPI-RP2 appears — leave it alone.
  2. Choose
  3. Enter BOOTSEL mode
  4. Erase the Pico
  5. Update the TS-2068 ROM
    1. Fit the P10 jumper if your board has one, and leave it on.
    2. Turn the TS-2068 on.
    3. Type OUT 244,3 and press ENTER — this switches to the Spectrum ROM.
    4. Type LOAD "" (J, then SYMBOL SHIFT+P twice) and press ENTER.
    5. Wait for DONE on the TV. This page follows along.
    6. Then switch the TS-2068 off again before the page installs the firmware. It will ask you to confirm.
  6. Install the firmware
  7. Copy the files

Done

Unplug the Pico’s USB cable (so the TS-Pico and its SD card really lose power), then switch the TS-2068 on. It should start with the new ROM and firmware — try SAVE "tpi:dir". Leave the P10 jumper fitted: it’s needed to put DOCK images in the flash.

Do it by hand instead

Everything the page does, as downloads. Switch the TS-2068 off, then put the Pico in BOOTSEL mode (see “It won’t connect” above) before each .uf2, and drag it onto the RPI-RP2 drive. The 2068 is on only for the ROM update step. When you’re done, unplug the USB cable before switching the 2068 on.

  1. flash_nuke.uf2 — erases the Pico; it comes back as RPI-RP2 by itself.
  2. From 1.1 / 1.5 only: upgrade.uf2 — then turn the 2068 on, type OUT 244,3 and LOAD "", wait for DONE, and switch the 2068 off again.
  3. firmware.uf2 (or as a .zip, if Windows blocks the .uf2).
  4. Then press Connect above and Start with “Erase” unticked — it only copies the files if the firmware is already current.

SD card files testers

The TS-Pico reads TAP programs and tpi:help text from a FAT-formatted SD card. Testers: unzip this to the root of the card, keeping the TAP/ and help/ folders. Everyone else can skip it — a ready-made SD card image will be provided separately.
