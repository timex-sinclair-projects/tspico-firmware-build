TS-Pico Web Updater prototype

Upload the TS-Pico release files to your Pico over USB — no Thonny needed.

Unsupported browser

This tool needs the WebSerial API, which is only available in Chromium-based browsers — Chrome, Edge, or Opera on Windows, macOS, Linux, or ChromeOS. Safari and Firefox are not supported, and there is no iOS option.

Open this page in Chrome or Edge and try again. The Thonny workflow in DEPLOY.md remains available as a fallback.

3 · Reboot

“Reboot Pico” restarts the firmware after an update. “Enter BOOTSEL mode” reboots into the RPI-RP2 drive so you can drag a new firmware.uf2 — no BOOTSEL button or paperclip needed.
