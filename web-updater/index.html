Web Updater

Install or upgrade the TS-Pico firmware from your computer, over the Pico’s USB cable.

Step 1Which computer are you using?

Windows needs a small updater program. On a Mac the update runs right in this page.

Step 2Download the TS-Pico Updater program

On Windows the browser can't write the firmware onto the Pico, so this page can't do the update. You need to download and run TS-Pico-Updater.exe instead. It does the same steps as this page, and there's nothing to install.

Download TS-Pico-Updater.exe

  1. Run the file you downloaded. If Windows says it doesn't know the program, click More info, then Run anyway.
  2. Close Thonny or anything else using the Pico, leave the 2068 switched off, and plug in the Pico's USB cable.
  3. Click Connect to TS-Pico, check the options, and click Start. The program finds the Pico by itself and tells you what to do.

The SD card files and the “do it by hand” downloads below still work on Windows. Use the browser updater anyway (only if you've installed the WinUSB driver for “RP2 Boot” with Zadig).

Unsupported browser

This tool needs the WebSerial API, which is only available in Chromium-based browsers — Chrome, Edge, or Opera on Windows, macOS, Linux, or ChromeOS. Safari and Firefox are not supported, and there is no iOS option.

Open this page in Chrome, Edge, or Opera and try again.

Step 3Upgrade your TS-Pico

Leave the TS-Pico plugged into the TS-2068 and connect the Pico’s Micro-USB port to this computer. Close Thonny or anything else using the Pico.

Switch the TS-2068 off before you start: the USB cable powers the Pico, and the Pico should only be reflashed or restarted with the 2068 off. You’ll turn the 2068 on for the ROM update (not on the v3 card), and the page tells you when to switch it off again.

  1. Connect
    Reads what’s installed and picks the right steps.
    It won’t connect / the Pico has no working firmware

    Put it into BOOTSEL mode by hand, then press Start below without connecting:

    1. Switch the TS-2068 off.
    2. Plug the USB cable into the Pico and your computer.
    3. Press and hold the Pico’s BOOTSEL button (the little white button next to the Micro-USB connector).
    4. While holding it, press and release the TS-Pico’s Pico reset button (or unplug and replug the USB cable).
    5. Release BOOTSEL. A drive named RPI-RP2 appears (RP2350 on the v3 card) — leave it alone.
  2. Start
    Every update erases the Pico and updates the TS-2068 ROM: the firmware needs its matching ROM. The v3 card is never erased and has no ROM step: its ROMs are slot files.
  3. Enter BOOTSEL mode
  4. Erase the Pico
  5. Update the TS-2068 ROM
    1. Fit the P10 jumper if your board has one, and leave it on.
    2. Turn the TS-2068 on.
    3. Type OUT 244,3 and press ENTER — this switches to the Spectrum ROM.
    4. Type LOAD "" (J, then SYMBOL SHIFT+P twice) and press ENTER.
    5. Wait for DONE on the TV. This page follows along.
    6. Then switch the TS-2068 off again before the page installs the firmware. It will ask you to confirm.
  6. Install the firmware
  7. Copy the files
  8. Modem firmware

Done

Unplug the Pico’s USB cable (so the TS-Pico and its SD card really lose power), then switch the TS-2068 on. It should start with the new ROM and firmware — try SAVE "tpi:dir". Leave the P10 jumper fitted: it’s needed to put DOCK images in the flash.

Do it by hand instead

Everything the page does, as downloads. Switch the TS-2068 off, then put the Pico in BOOTSEL mode (see “It won’t connect” above) before each .uf2, and drag it onto the RPI-RP2 drive. The 2068 is on only for the ROM update step. When you’re done, unplug the USB cable before switching the 2068 on.

  1. flash_nuke.uf2 — erases the Pico; it comes back as RPI-RP2 by itself.
  2. upgrade.uf2 — then fit the P10 jumper if your board has one (and leave it fitted), turn the 2068 on, type OUT 244,3 and LOAD "", wait for DONE, and switch the 2068 off again. The firmware needs its matching ROM.
  3. firmware.uf2 (or as a .zip, if Windows blocks the .uf2).
  4. The firmware’s files still have to go onto the Pico, and only the guided run copies them: press Connect above and Start.

OptionalSD card files

The TS-Pico reads TAP programs and tpi:help text from a FAT-formatted SD card. Testers: unzip this to the root of the card, keeping the TAP/ and help/ folders. Everyone else can skip it and use the software library below.

Download SD card files (.zip)

The TS-2068 software library: 1,300+ programs from the Timex Sinclair Software Archive, each one tested on a TS-Pico, in category folders under TAP/. Unzip it to the root of the card the same way. Its catalog says what each program is and how to load it.
