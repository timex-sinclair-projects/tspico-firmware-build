TS-Pico Command             ZX48
--------------------------------
SAVE "tpi:zx48"

Switch TS-Pico to Spectrum mode.
It shows some help when invoked.
You can do only a few TS-Pico 
commands from Spectrum mode:
- List the current directory.
    SAVE "tpi:dir"
  Giving a name or pttern work:
    SAVE "tpi:dir *.tap"
- Mount a .tap file from the
  current directory.
    LOAD "tpi:name.tap"
  Index numbers work as well.
- LOAD programs and data from 
  the mounted .tap file.
    LOAD ""  or  LOAD "name"
- SAVE programs and data to a
  new .tap file.
    SAVE "name"
It is a good idea to have all of
your Spectrum programs in one 
directory that you change into
before switching to Spectrum
mode.

To leave Spectrum mode, first
use OUT 244,0 then press the
TS-Reset button. When you see
the Timex and TS-Pico copyright
messges, then do: OUT 14,14.

Some advanced CODE options are
also available:
  SAVE "tpi:zx48"CODE m,n

If m=1, then don't display the
help message, m=0 displays it. 

n=0: Use the default tape loader
set by the ZX_TAPE_COMPAT
setting.

n=1: Use regular tape LOAD
routine.

n=2: Use compatible LOAD with
the default buffer size.

n>=16384: Use compatible LOAD
with the given buffer size of n.
See ZX_TAPE_COMPAT in config.ini

Note that while the dock bank is
mapped to the 2068 cartridge
port, you can't use zx48 mode,
and it will give error Q while
the dock is the cartridge slot.
See dock.

See also: OUT, config, load,
save, dock
