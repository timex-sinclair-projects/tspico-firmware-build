BASIC Function            INKEY$
--------------------------------
INKEY$ [#s]

Reads the keyboard and returns a
string with the key pressed as
if in L or C mode. An empty
string is returned if no key or
more than one key is being
pressed.
  10 LET k$=INKEY$
  20 IF k$="" THEN GO TO 10

The optional stream number
causes a character to be read
from stream #s instead of the
keyboard. The keyboard is stream
#1, and you can't use #2 since 
that is the screen.

See also: CHR$, CODE, INPUT,    streams
