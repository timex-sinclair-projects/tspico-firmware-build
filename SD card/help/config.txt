TS-Pico config.ini in Pico flash
--------------------------------
A file in the root folder of the
TS-Pico's internal flash memory.
This can be accessed with the 
Thonny Python development 
application. It is a JSON format
file of key/value pairs:

  {"ROM_VERSION": "2.0",
   "LOG_LEVEL": 2,
   "FW_VERSION": "2.0",
   "ZX_TAPE_COMPAT": false,
   "DCK_SLOT": 0,
   "ROM_SM": 10,
   "ROM_SLOT": 1,
   "DOCK_CART": false,
   "VERBOSE": false}

LOG_LEVEL: See help for loglevel
ZX_TAPE_COMPAT: See ZX48
DCK_SLOT: See dock
ROM_SLOT: See boot
ROM_SM: memory types, 4 bits:
  DOCK*4 + BOOT, each 1 = SRAM,
  2 = flash, 3 = SD card (v3)
  (10 = both flash)
DOCK_CART: See dock
VERBOSE: See verbose
MODEM_MODE, MODEM_BAUD,
  MODEM_IDLE_MIN: See modem (v3)
AUTOMOUNT: See automount
SPEECH_GREETING: See greet (v3)
PRINTER_AUTOLF, PRINTER_AUTOPG:
  See autolf, autopg
