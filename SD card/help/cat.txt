BASIC Command                CAT
--------------------------------
CAT [#n;][name]

Lists files on the SD card.
CAT         the current dir
CAT "games" another directory
CAT "*.tap" matching names:
            * any run, ? one
            character
CAT "g.tap" the blocks in a
            .tap file
CAT ""      the mounted .tap
CAT #4      into the file open
            on stream 4; also
            CAT #4;"*.tap"

Files LOAD "tpi:nn" can use come
first, with their number (type
two digits or more: "tpi:03").
All other files follow,
unnumbered.
name can be any string
expression, e.g.
CAT d$+"/*.tap". A name that is
not found gives Report F.

Same as SAVE "tpi:dir name".

See also: move, erase, format,
dir, tapdir
