TS-Pico Command              SAY
--------------------------------
SAVE "tpi:say text"
SAVE "tpi:say"

*v3 board only*
Speaks the text or allophones
given. Give no text to stop
speaking. The speech will
continue in the background, and 
any other say commands will have
their speech wait in a queue.

  SAVE "tpi:say HELLO, THERE"
  SAVE "tpi:say [HH1 EH LL OW]"

Allophones can be specified in 
the text by including them in
square brackets. See the user
manual for more info.

The length of text is limited to
23 characters in this command.
For longer text (unlimited), use
the v: channel to sent text to.
See OPEN#.

See also: OPEN#, greet
