BASIC Command             FORMAT
--------------------------------
FORMAT "new.tap"
Makes a new, empty .tap file and
mounts it with append on, ready
to SAVE into. ".tap" may be left
off. Another extension, as in
"notes.txt", is Report Q.

FORMAT "tools/"
Makes a directory.

Neither overwrites anything that
is already there (Report F).
It never formats the SD card.

FORMAT ":GAMES"
Names the SD card: its label, as
a PC or Mac shows it. FORMAT ":"
takes the label off. See label.

Same as SAVE "tpi:format name".

See also: cat, erase, append, md
label
