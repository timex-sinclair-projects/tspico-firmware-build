BASIC Command             ON ERR
--------------------------------
ON ERR GO TO n
ON ERR CONT
ON ERR RESET

This controls the error trapping
feature. This does not exist in
ZX Spectrum BASIC.

  ON ERR GO TO n
Enable error trapping and jump
to the line n when an error
occurs. The routine can examine
these system variables, then
branch elsewhere, possibly to
the error line or the one after
it:

 ERRT 23739 error code
 ERRC 23736 line of error
 ERRS 23738 statement of error
 ERRLN 23734 the GO TO line

ERRT is the report index: 0 for
"0 OK", 10 for A, 15 for F, 27
for R. So PEEK 23739 = 15 means
report F. Counting runs 0-9 then
A-R with no gap.

  ON ERR CONT
This will simply ignore the
error and continue if possible.
The ERR system variables will
be set.

  ON ERR RESET
Turns off the error trapping
function, and errors will stop
the program and report as usual.

This keyword has the code of '{'
(123) and appears in its place
on the ZX Spectrum keyboard.
When you type it in L mode, you
get the symbol but the keyword
when in K mode.

See also: RESET, CONTINUE, GOTO,
sysvars, errors
